推荐几个好用的在线 JSON 工具

平时开发中 JSON 是最常见的数据格式之一。格式化、校验、对比、转格式……每次都要找工具。这半年试了十多个在线 JSON 工具，整理出这份推荐清单。

在线 JSON 工具，怎么选？

先说说我选工具的标准：

  1. 速度快 — 就在浏览器里处理，不要上传到服务器
  2. 功能全 — 格式化、校验、对比、转换最好一个站搞定
  3. 隐私友好 — 敏感数据不该离开本地
  4. 免费 — 这种基础工具值得免费

根据这些标准，下面是我用过觉得不错的。

1. JSON Process（我目前在用的主力）

https://jsonprocess.app

这是我最近一直在用的工具站，20+ 个工具全部在一个站上：

基础功能：

  • 格式化/美化（支持 2 空格、4 空格缩进），带语法高亮
  • 压缩/最小化，把 JSON 缩成一行
  • 语法校验，精确定位错误行号
  • 转义/反转义

高级功能：

  • JSON Diff（对比两个 JSON 的差异）
  • JSONPath 查询（类似 XPath 的 JSON 查询语言）
  • 树形视图浏览
  • JWT 解码（不传服务器，本地解码）

格式转换：

  • JSON ↔ CSV
  • JSON ↔ YAML

代码生成：

  • JSON → Java POJO 实体类
  • JSON → TypeScript 类型定义
  • JSON Schema 生成

其他：

  • 支持中文、英文、西班牙语、阿拉伯语
  • PWA，可以安装到桌面当 App 用
  • 全免费，无广告

特别提一下 JSON Playground

它有一个”Playground”功能，粘贴一次 JSON，在 5 个标签页里自由切换：格式化 / 树形视图 / 代码生成 / Schema / 数据统计。开发的时候经常要在不同视角看同一段 JSON，这个功能很实用。

2. JSONLint

https://jsonlint.com

老牌 JSON 校验工具，名气很大。特点：

  • 专注校验，做得非常精
  • 界面简洁
  • 可以保存验证历史

缺点：功能单一，只有校验和格式化。要做转换、对比之类的还得另外找工具。

3. JSON Compare

https://www.jsondiff.com

专门做 JSON 对比的工具。界面左右对比，差异部分高亮显示，新增、删除、修改一目了然。

缺点是只能对比，没有格式化或转换功能。

4. Code Beautify

https://codebeautify.org/json-beautifier

一个比较大的工具集合，不只有 JSON，还有 XML、HTML、CSS 等各种格式化工具。

好处是功能多，坏处是广告太多了，页面加载慢，有些功能还要上传到服务器。

5. 在线 JSON 编辑器（JSON Editor Online）

https://jsoneditoronline.org

支持树形编辑和文本编辑双视图，对于复杂 JSON 结构来说，树形视图的拖拽编辑确实方便。

不过功能偏编辑器方向，缺少格式转换和代码生成。

我的推荐组合

场景 推荐工具
日常开发（格式化+校验+转换+代码生成） JSON Process — 一个站搞定
纯校验 JSONLint — 老牌可靠
深度的 JSON 对比 JSON Process 的 Diff 功能或 jsondiff.com
编辑复杂 JSON 结构 JSON Editor Online — 树形编辑方便

如果你平时经常跟 JSON 打交道，建议把 JSON Process（https://jsonprocess.app） 加到浏览器书签里。20+ 个工具一站解决，少跳转几个站，效率会高很多。
