程序员副业：做工具站能赚多少钱

一个 Java 后端程序员，利用下班时间做了个在线 JSON 工具箱，上线一个月后 Google 开始给流量了。这篇文章聊聊真实的副业经历、收入和踩坑。

这篇文章不说大道理，只说真实的经历和数字。

为什么选择做工具站

想搞副业赚钱，程序员的选择其实不多：

方式 收入潜力 门槛 优缺点
接外包 中高 中 累，跟上班没什么区别
写付费课程 高 高 需要影响力，录课也累
做开源 低 中 靠打赏，不太稳定
做工具站 中 低 一次开发，长期流量，被动的
做 SaaS 产品 高 高 需要运营和持续维护

工具站有一个很吸引人的特性：一次开发，长期有流量。技术上不需要很复杂，纯前端就能跑，不需要服务器，部署到 Vercel/Netlify 免费。

我选的赛道是 JSON 工具。原因很简单：这是程序员刚需，每天都有成千上万的开发者需要格式化、校验 JSON。

投入

时间投入（晚上和周末）：

  • 学习 React + TypeScript：1 周（白天写 Java，晚上看文档 + 写 demo）
  • 搭建第一个工具（JSON 格式化）：2 个晚上
  • 扩展到 8 个工具：1 周
  • SEO 优化 + 内容建设：3 天
  • 继续扩展到 20+ 个工具 + 多语言 + PWA：1 周

金钱投入：

  • 域名 jsonprocess.app：约 ¥60/年
  • Vercel 托管：免费
  • Google Analytics：免费
  • 总投入：¥60

收入：目前是 0

这是最诚实的部分——目前还没有收入。

原因很简单：

  1. 网站刚上线，流量还很小，每天几十个 UV
  2. 没有挂 AdSense（Google 要求网站至少有几篇文章和有价值的内容才能通过审核）
  3. 没有做任何付费推广

那什么时候能赚钱？

大概算了一笔账：

假设：

  • 每天 1000 UV（工具站做到这个量不算太难）
  • AdSense 千次展示收入（RPM）约 $1-5（开发者工具类 RPM 相对高一些）
  • 日均收入：$1-5
  • 月收入：$30-150（约 ¥200-1000）

要达到这个流量：

  • 需要 3-6 个月的 SEO 积累
  • 需要 15-20 篇有质量的博客文章
  • 工具本身要够好用，用户愿意收藏

做工具站赚钱的逻辑很清晰——拼的是耐心和内容。

做工具站正确的运营方式

1. 工具要做”工具箱”，不要只做单个工具

单个工具竞争对手太多，SEO 很难做。做工具箱的好处是：

  • 每个工具都是一个独立的着陆页
  • 相互之间可以链接，形成站内链轮
  • 用户在一个站上解决多个需求，留存率更高

2. SEO 是第一生产力

开发者工具站，流量 90% 来自搜索引擎：

  • Title 和 Description 必须是独立写的，不要用模版
  • 内容要有深度，不是只放一个输入框就完事了
  • FAQ 结构化数据能拿到 Google 的折叠展示
  • 内链每个工具底部链到 3 个相关工具
  • 外链需要时间积累，可以在知乎、掘金、V2EX 分享工具

3. 运营 > 技术

工具本身只需要”够好”，不需要”完美”。我的经验：

  • 工具做 80 分就可以上线了
  • 剩下的 20 分根据用户反馈来优化
  • 时间应该花在写文章、发帖子、搞 SEO上
  • 内容网站 + 工具站的组合效果远好于纯工具站

给想搞副业的程序员一些建议

如果是技术选择：

React + Vite + Vercel 是最低成本方案。免费、快、容易部署。不需要服务器，运维成本为 0。

如果是赛道选择：

找到”程序员刚需 + 竞品不太多”的工具领域。JSON 工具竞争大但需求也大；一些冷门格式（比如 TOML、HCL、EDN）的工具竞争小但需求也小。

如果是心态建设：

副业赚到大钱需要时间。工具站三个月没流量是正常的，半年开始有起色也是正常的。关键是坚持做内容、持续优化 SEO。

如果只想靠技术实现财务自由：

工具站只是一个起步。真正赚钱的是 SaaS 产品。工具站可以帮你积累流量和用户，然后转化到付费产品上。用免费工具换流量，用付费产品做收入，这是我最看好的模式。

下一步计划

  • 继续写博客（SEO 内容站）
  • 流量稳定后挂 AdSense
  • 考虑做 Pro 版（高级功能付费）
  • 做第二个工具站（换个赛道复制模式）
